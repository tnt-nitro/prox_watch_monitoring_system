# Security & Privacy Policy

## Grundprinzipien

- Offline-First
- No Telemetry
- No Cloud
- No Phone-Home

## Verbotene Inhalte im Repository

- Personenbezogene Daten
- IP-Adressen, Hostnames, Gerätenamen
- Container-IDs, MAC-Adressen
- Reale Logs, Dumps, Backups
- Reale Verzeichnisstrukturen
- Zugangsdaten / Secrets

## Erlaubte Inhalte

- Anonyme Beispieldateien (*.example,*.template)
- Dokumentation ohne reale Referenzen
- Installer-Logik ohne Nutzerdaten

## Konfiguration

- Reale Konfigurationen werden **lokal** gespeichert
- Reale Konfigurationen sind **nicht versioniert**
- Repository enthält **nur Beispiele**

## Meldung von Sicherheitsproblemen

- Keine automatische Übermittlung
- Keine Cloud-Dienste
- Issues **ohne** sensible Informationen
