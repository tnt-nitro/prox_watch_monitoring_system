# Contributing Guidelines

## Datenschutz (Pflicht)

Beiträge dürfen **keine**:

- realen IP-Adressen
- realen Hostnamen
- realen Pfade
- realen Logs
- realen Systemnamen
enthalten.

## Konfigurationsdateien

- Nur *.example /*.template
- Keine produktiven Dateien
- Keine lokalen Pfade

## Code

- Keine Telemetrie
- Keine externen Dienste
- Keine versteckten Netzwerkzugriffe

## Tests / Beispiele

- Nur synthetische Daten
- Keine Rückschlüsse auf reale Systeme

## Verstöße

PRs mit Verstößen werden **sofort abgelehnt**.
